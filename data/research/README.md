# ZeroRealm Research 运营台账

这是面向单人、每周 8–15 小时执行的最小研究运营系统。它只记录可验证的进展；不要预填访谈、反馈、传播或关系证据。

## 每周节奏

1. 筛选 2–3 条能改变运营、设备或供应链判断的信号，记录来源链接与发布日期。
2. 更新本周期的问题、反证和待验证假设；每两周交付一篇深度研究。
3. 仅在获得明确反馈后，向 `feedback-log.json` 追加一条记录。
4. 周末复核核心主体、观察主体和背景主体的维护状态，并导出网站快照。

## 事实边界

- 节点收录用于研究覆盖，不构成合作、供货、投资或采购事实。
- 公开关系须有公开 URL、发布日期和 A/B/C 证据等级，且状态为 `confirmed`。
- 从业者反馈是选题信号，必须标记为反馈，不能替代公开事实证据。

## 发布前导出

在数据仓库根目录运行：

```powershell
python scripts/export_industry_graph.py --output <website>/data/industry-graph.json
```

导出后在网站仓库运行测试、检查与构建，确认公开页面没有把观察关系或空证据关系发布出去。
