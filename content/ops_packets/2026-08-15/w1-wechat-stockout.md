# 柜机缺货排查清单：先查这 7 步再补货

> 适用范围：智能柜运营商 / 运营负责人。  
> 口径说明：缺货相关定义为 **零域参考口径 / 企业内部实验口径**，不是行业统一标准。  
> 发布约束：本包为 **草稿就绪** 材料；须人工审核后创建/更新微信草稿，**禁止**自动发表与群发。

## 开场：缺货信号 ≠ 真实缺货

柜机、后台或巡检报出“缺货”，常见有三种完全不同的事：

1. **真实缺货**：应售货道/货品 无货，消费者买不到  
2. **运营态空置**：主动下架、清场、调改货道、季节性停售  
3. **数据态噪声**：库存不准、离线未同步、测试/锁定货道被算进应售  

**观点：** 报警后立刻按原货品加补，是最高频的浪费之一。先排查，再补货。

## 7 步排查（按顺序，可中断）

### 步骤 1：定性——这是信号还是真实缺货？

- [ ] 是否处于主动下架 / 清场 / 调改窗口？  
- [ ] 该货道是否仍标记为“应售”？  
- [ ] 近 24–48 小时是否有盘点或系统重同步？  

**停止本步条件：** 若为计划内下架，记录原因后结束，不进入补货。

### 步骤 2：核对库存口径与账实（库存准确率）

- [ ] 系统库存、货道库存、最近盘点是否一致？  
- [ ] 不一致时，优先安排盘点/校正，而不是加倍补货  
- [ ] 记录：`核对一致货品数 / 抽盘货品数` 本周抽样结果（企业内部口径）  

**推断：** 账实不稳时，缺货率与补货任务都会被放大误差。

### 步骤 3：确认是否为畅销货品反复断货

- [ ] 该货品近两周是否多次进入缺货？  
- [ ] 同点位是否存在“高动销 + 高缺货”组合？  
- [ ] 若是长尾货品偶发空置，优先级应低于畅销断货  

### 步骤 4：检查补货任务是否超时（补货及时率）

- [ ] 是否已生成补货任务？  
- [ ] 是否超过约定时效（点位通行/城市时效不同）？  
- [ ] 超时原因：运力、仓配、门锁通行、排班，还是任务未派？  

公式提示：`准时补货任务数 / 补货任务总数`

### 步骤 5：确认设备是否在线可售（设备在线率）

- [ ] 设备当前在线吗？  
- [ ] 支付 / 识别 / 柜门是否异常？  
- [ ] 离线期间产生的“缺货”是否可能为同步延迟？  

公式提示：`在线设备数 / 在管设备数`

### 步骤 6：检查点位 × 货品是否错配（动销）

- [ ] 该货品在本点位是否长期低动销？  
- [ ] 缺的是“该点位真正有人买的货”，还是“仓库想清掉的货”？  
- [ ] 需要的是补货，还是调货 / 换品？  

公式提示：`有销售货品数 / 在售货品数`

### 步骤 7：决策与停止规则

在 1–6 步结论清晰后，只选一个主动作：

| 决策 | 何时选 | 证据最低要求 |
| --- | --- | --- |
| 补原货品 | 真实缺货 + 畅销/有效动销 + 设备可售 + 任务可执行 | 步骤 1–5 通过 |
| 调货/换品 | 反复缺货但动销差，或点位错配 | 步骤 3+6 |
| 先盘点校正 | 账实不一致主导 | 步骤 2 |
| 先运维 | 离线/支付等导致不可售 | 步骤 5 |

**停止规则（必须写进周复盘）：**  
若**同一货品连续两周**出现真实缺货，但团队仍不调货/不换品/不改安全库存，则本周强制进入选品与结构复盘，而不是第三次原样加补。
